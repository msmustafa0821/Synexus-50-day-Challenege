# Day 11 – JavaScript Engine & DOM Fundamentals

## 📖 Overview

Day 11 marked the transition from building static web pages to creating interactive user experiences with JavaScript. The primary focus was understanding how JavaScript connects to an HTML document, interacts with the Document Object Model (DOM), and responds to user actions through event-driven programming.

## 🎯 Objectives

* Connect a JavaScript file to the HTML document using the `defer` attribute.
* Understand how the browser constructs and exposes the DOM.
* Select HTML elements using `document.querySelector()`.
* Respond to user interactions with `addEventListener()`.
* Dynamically update webpage content using `textContent`.
* Manipulate CSS classes with `classList.toggle()`.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)

## ✨ Features Implemented

* Linked the external `script.js` file using the `defer` attribute.
* Selected the Hero section heading and primary button using DOM selectors.
* Attached a click event listener to the Hero button.
* Updated the Hero headline dynamically when the button was clicked.
* Implemented an optional active-state CSS class toggle to change the heading color interactively.

## 📚 Key Concepts Learned

* JavaScript execution in the browser.
* Importance of the `defer` attribute.
* Understanding the Document Object Model (DOM).
* DOM element selection using `querySelector()`.
* Event-driven programming with `addEventListener()`.
* Updating page content using `textContent`.
* Dynamic styling using `classList.toggle()`.
* Proper usage of `const` for DOM element references.
