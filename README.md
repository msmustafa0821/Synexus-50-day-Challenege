# Synexus Community Landing Page

A semantic HTML5 landing page enhanced with fundamental CSS styling as part of the Synexus 50-Day Web Development Challenge.

📖 About

On Day 2, the project was improved by introducing CSS. A universal reset was applied to remove browser default styles, CSS variables were created for consistent colors, and basic typography styling was added to create a clean foundation for future development.

🚀 Features

Semantic HTML5 structure

External CSS stylesheet

Universal CSS Reset

CSS Box Model (box-sizing: border-box)

CSS Variables (:root)

Global typography styling

Hero heading styled using CSS variables


🛠️ Technologies Used

HTML5,
CSS3

📂 Project Structure

├── index.html

├── style.css

├── Synexus.png

└── README.md

▶️ How to Run

Download or clone the repository.

Open index.html in your web browser.

🎯 Learning Objectives

Learn how to link an external CSS file.

Understand the CSS Box Model.

Apply a Universal Reset.

Create and use CSS variables.

Build a clean and consistent styling foundation.
