### Day 4 – Component Design & UI Hierarchy

**Focus:** Reusable UI components and visual hierarchy.

#### What I built

* Created a reusable `profile-card` component.
* Added member image, name, role, and LinkedIn button.
* Duplicated the component for three team members to test consistency.

#### What I learned

* **Component-driven design:** build one reusable structure and repeat it with different content.
* **Visual hierarchy:** make the name more prominent and the role less prominent.
* **Padding:** creates breathing room inside the card.
* **Border radius:** gives the card a modern rounded appearance.
* **Box shadow:** adds depth and separates the card from the background.
* **Hover effects:** using `:hover` and `transform: translateY(-5px)` to create a lift effect.

#### CSS concepts practiced

* `.profile-card`
* `.profile-card h3`
* `.profile-card p`
* `.profile-card a`
* `.profile-card:hover`

#### Outcome

The Core Team section now uses a consistent, reusable card component with improved spacing, typography, button styling, and an interactive hover effect, making the UI look much more professional.
