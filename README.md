# Synexus Community Landing Page

A semantic HTML5 landing page created for the Synexus community project.

## 📖 About

This project demonstrates the use of semantic HTML5 elements to build a well-structured, accessible, and SEO-friendly community landing page.

## 🚀 Features

- Semantic HTML5 structure
- Navigation bar
- Hero section
- About section
- Initiatives section
- Core Team section
- Footer with social links

## 🛠️ Technologies Used

- HTML5

## 📂 Project Structure

```
├── index.html
├── Synexus.png
└── README.md
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open `index.html` in your web browser.

## 🎯 Learning Objectives

- Understand semantic HTML
- Build a proper document hierarchy
- Improve accessibility and SEO basics
- Practice structuring a landing page
